Sol JK SJK

Sol's flavor of JKR, the Rust engine for Jedi Knight: Jedi Academy multiplayer by Bishop. It follows JKR closely and adds a classic look, reliable joining and many gameplay and presentation fixes.

Download Source code Documentation

What SJK adds

Classic menu style

Menus after the retail game: profile, setup and controls pages, the original connect and loading screens, and no map behind the menu.

Reliable joining

Lost handshake packets and lost gamestates are recovered, and older 72-bone player models no longer stop you from joining a server.

Sharp retail fonts

The optional game fonts stay crisp at 1440p and 4K.

Smooth frame pacing

The FPS cap follows your monitor's refresh rate by default and holds its exact rate, which also helps recording and streaming.

Material maps

Optional rend2-style normal and specular maps for world surfaces, with a local generator for the maps you have installed.

Gameplay fixes

Third-person camera, Force Speed afterimages, saber trails, death animations, keyboard layouts and more.

Getting started

You need a legally obtained copy of Jedi Academy; SJK uses its GameData folder and ships no game assets. To build from source, install Rust 1.88 or newer, then:

cargo build --release -p jkr-viewer -p jkr-dedicated
./target/release/jkr-viewer /path/to/GameData

The programs keep JKR's names. See the README for the dedicated server and platform notes.
