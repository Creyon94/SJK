# JoF Force presets

These 22 community-authored `.fcf` files come unchanged from
[JoF EJK pull request #23](https://github.com/JediofFreedom/JoF_EJK/pull/23),
revision `9750845d194ced3d4ef86fcb80ea482339f629d1`, under
`assets/japro/forcecfg`. Credit: Toxiee and the JoF EJK contributors;
distributed under the upstream project's GNU GPL version 2 (see the repository
root `LICENSE`). They contain Force profiles, not retail game assets.

SJK embeds them as a lowest-priority content mount. Their names, colour codes
and Force values are preserved. Installed packs and player-saved templates can
replace them. Selecting a template loads the normal Force draft, which applies
the current rank, side and server rules; it grants no extra powers or points.
