# Credits shown by the credits page (main menu > Credits, the in-game SJK menu, or
# the `credits` console command). The file is built into the client
# (include_str!) and parsed once; unit tests in credits_data.rs check it, so
# `cargo test` catches a broken edit. CREDITS.md stays the full written record.
#
# Format, in display order:
#
#   == Section title   Starts a section (a later "== Supporters" needs no code).
#   [Name]             Starts a card in the current section.
#   github: handle     Optional GitHub account, shown as @handle.
#   role: text         Required: one line under the name.
#   did: text          One contribution per line (repeat the key); optional.
#
# Lines starting with '#' and blank lines are ignored. ASCII only: the menu fonts
# draw bytes. Add a person when their first change lands; add lines as they code.
