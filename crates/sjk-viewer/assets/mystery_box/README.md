# Mystery box

The mystery boxes' sounds (SJK's own, [mystery-boxes.md](../../../../docs/mystery-boxes.md)).
Both are made by [mystery_box_assets.py](../../../../scripts/mystery_box_assets.py) from
synthesized tones (SJK's own tune, nothing taken from another game), so neither is edited
by hand.

| File | Game path | What |
| --- | --- | --- |
| `roll.wav` | `sound/sjk/mystery_box/roll.wav` | The roll: a music box tune slowing like a wound-down spring, its last chord at 5.5 s as the roll stops on what came out, 22050 Hz mono |
| `take.wav` | `sound/sjk/mystery_box/take.wav` | Taking what came out: a quick rising sparkle |
