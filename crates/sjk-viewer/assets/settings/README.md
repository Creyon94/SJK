# Settings icons

The settings menu's icons ([settings_icons.rs](../../src/settings_icons.rs)): holocron
faces, a bronze frame with bevelled corners round a glowing blue crystal panel and a
bold white-blue symbol, generated by Sol with Google Flow as one board of 32
(`Game_icon_grid_on_display_2K_20261013005251`, 13/10/2026, kept outside the
repository) and cut out by [settings_icons.py](../../../../scripts/settings_icons.py).
They replaced a grey metal board (07/10/2026) and, the same day, a gold-on-navy set
whose fine rims read as noise at the rail's size. They are SJK's own art; no retail
image is used.

Each is 128x128, the UI atlas cell, on transparency along the face's own outline
with a soft edge. The atlas has 32 settings cells, all used. Besides Settings' rail
(its categories and the search's groups), the classic Settings group lists
(`Entry::icon` in [layout.rs](../../src/menu/classic/layout.rs)), the in-game menu
(chat) and other SJK pages use them.

## Regenerating

With Python 3 and Pillow, numpy and scipy (`pip install pillow numpy scipy`), from
the repository root:

```sh
python scripts/settings_icons.py Game_icon_grid_on_display_2K_20261013005251.jpg crates/sjk-viewer/assets/settings
```

The script finds the board's 32 faces (four rows of eight) and names them in board
order:

1. first_setup, video, graphics, sound, mouse_joystick, key_bindings, game_options,
   interface;
2. hud, chat, mods, network, scoreboard, identity, settings, quick_wheel;
3. image, lighting, shadows, weather, camera, crosshair, nameplates, movement;
4. interaction, weapons, force_powers, other_controls, changelog, credits, update,
   import.
