# Settings icons

The settings menu's icons ([settings_icons.rs](../../src/settings_icons.rs)): navy
discs with a gold rim and a gold symbol, in the SJK UI's colours, generated by Sol
with Google Flow as five sheets of eight (13/10/2026, kept outside the repository;
the grey metal board of 07/10/2026 before them) and cut out by
[settings_icons.py](../../../../scripts/settings_icons.py). They are SJK's own art;
no retail image is used.

Each is 128x128, the UI atlas cell, on transparency with an anti-aliased round edge.
The atlas has 32 settings cells, all used. Besides Settings' rail (its categories
and the search's groups), the classic Settings group lists (`Entry::icon` in
[layout.rs](../../src/menu/classic/layout.rs)), the in-game menu (chat) and other
SJK pages use them.

## Regenerating

With Python 3 and Pillow, numpy and scipy (`pip install pillow numpy scipy`), from
the repository root, the five sheets in the order they were generated:

```sh
python scripts/settings_icons.py sheet1.jpg sheet2.jpg sheet3.jpg sheet4.jpg sheet5.jpg crates/sjk-viewer/assets/settings
```

The script finds each sheet's eight discs (two rows of four) and names them in
sheet order:

1. first_setup, video, graphics, sound, mouse_joystick, key_bindings,
   game_options (also saved as gameplay), interface;
2. hud, chat, mods, network, (sliders, unused), scoreboard, identity, settings;
3. image, lighting, shadows, weather, camera, crosshair, nameplates, (quill, unused);
4. movement, interaction, weapons, force_powers, other_controls, changelog,
   credits, update;
5. import, then seven spares (shield, holocron, trophy, bell, globe, lightning
   bolt, key), unused.

Every sheet used the same words, with its own eight symbols, and Sol's first sheet
as a reference image for the others:

```
Game UI icon sheet, 8 round icons in 2 rows of 4 on a plain black background.
Deep navy discs with thin gold rims and clean gold line-art symbols, minimal
premium sci-fi menu style: <eight symbols>. Same size, evenly spaced, no text.
```
